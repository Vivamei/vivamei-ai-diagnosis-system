# 01 · 部署前准备

## 适用读者与目标

本文档面向首次在阿里云上部署本项目的技术人员。完成本文档所述准备工作后,可进入 [02-部署实施.md](./02-部署实施.md)。

本阶段目标:

- 在阿里云上创建部署所需的全部云资源。
- 采集所有连接地址、账号密码、密钥等信息,汇总于 §14 的信息汇总表。
- 完成域名实名认证、ICP 备案、SSL 证书申请。
- 生成应用侧使用的加密密钥。

预计操作耗时 2 至 3 小时(不含 ICP 备案的等待时间)。ICP 备案通常需要 1 至 2 周,请在项目立项后立即启动。

## 0. 部署架构

```
用户浏览器 ── HTTPS(443) ── ECS
                                ├─ web 容器  nginx: TLS 终止、静态资源、/api 反向代理
                                ├─ api 容器  uvicorn 监听 8000
                                └─ cron 容器 定时任务
                                     │  VPC 内网
                                     ├─ RDS MySQL 8.0(托管)
                                     ├─ KVStore Redis(托管)
                                     └─ OSS、短信、内容审核(阿里云 API)
```

架构要点:

- MySQL 与 Redis 使用阿里云托管服务,不在 ECS 上自建。
- 除 22、80、443 端口外,其他端口不对公网开放。数据库与 Redis 仅允许通过 VPC 内网访问。
- 配置分两层:非敏感配置构建时打包进镜像;密钥类配置(数据库/Redis 凭证、AccessKey、JWT、手机号加密密钥)运行时通过服务器 `/etc/venus-4s/.env` 注入。

依据 `apps/api/pyproject.toml` 引入的 SDK 与 `apps/api/app/core/config.py` 的配置字段,项目实际使用以下阿里云资源。

| RDS MySQL 8.0 | 业务数据库 | §4 |

| 短信服务(dysms) | 登录验证码 | §7 |
| 内容审核(Green) | 图片与文本审核 | §8 |
| 容器镜像服务(ACR) | 存储构建后的 api、web 镜像 | §9 |

## 2. 创建 RAM 子账号

RAM 子账号用于应用程序调用短信、OSS、内容审核等云服务。

**安全要求**:应用程序不得使用主账号 AccessKey。主账号 AccessKey 拥有全部权限,一旦泄露将影响整个阿里云账号的安全。

**费用说明**:创建 RAM 子账号、AccessKey、授权策略均不收费。子账号调用云服务产生的费用统一记入主账号。

### 2.1 创建子用户

1. 登录阿里云控制台,进入访问控制 RAM:<https://ram.console.aliyun.com/>
2. 在左侧导航栏选择"身份管理 > 用户",单击"创建用户"。
3. 填写用户信息:
    - 登录名称:`venus-app`
    - 显示名称:`薇分美学后端服务`
    - 访问方式:仅勾选"OpenAPI 调用访问"
4. 单击"确定"完成创建。系统可能要求短信或 MFA 二次验证。

### 2.2 创建 AccessKey

创建用户时若已勾选"OpenAPI 调用访问",系统将在完成页直接显示 AccessKey ID 和 AccessKey Secret。

如需事后创建:进入用户列表,单击 `venus-app`,在"认证管理"页签下单击"创建 AccessKey"。

对话框中需要保存以下两项信息:

| 项目 | 说明 | 对应配置项 |
|---|---|---|
| AccessKey ID | 立即记录 | `ALI_ACCESS_KEY_ID` |
| AccessKey Secret | 仅在创建时显示一次,请单击"下载 CSV"或立即复制。窗口关闭后无法再次查看,只能删除后重建。 | `ALI_ACCESS_KEY_SECRET` |

### 2.3 授权

1. 进入用户列表,单击 `venus-app`,在"权限管理"页签下单击"新增授权"。
2. 授权范围选择"整个云账号",添加以下系统策略:

| 用途 | 策略名称 |
|---|---|
| 短信服务 | `AliyunDysmsFullAccess` |
| OSS 对象存储 | `AliyunOSSFullAccess` |
| STS 临时凭证 | `AliyunSTSAssumeRoleAccess` |
| 内容审核 | `AliyunYundunGreenWebFullAccess` |

3. 单击"确定"完成授权,授权立即生效。

上线阶段可先使用上述 FullAccess 策略,运行稳定后再收敛为最小权限策略。

### 2.4 记录主账号 ID

主账号 ID 是一串 16 位数字,后续拼接 OSS STS 角色 ARN 时需要用到。

查看方式:单击控制台右上角头像,选择"账号管理",页面顶部即为"账号 ID"。

## 3. 创建 RAM 角色 `venus-uploader`

前端上传照片时不能直接使用应用侧的 AccessKey,而是由后端通过 STS AssumeRole 换取仅允许上传至指定 OSS 前缀、有效期为 300 秒的临时凭证下发给前端。此机制需要一个 RAM 角色。

### 3.1 创建角色

1. 进入 RAM 控制台,选择"身份管理 > 角色",单击"创建角色"。
2. 可信实体类型选择"阿里云账号",默认为当前主账号。
3. 角色名称填写 `venus-uploader`,单击"完成"。

### 3.2 附加权限策略

在角色详情页单击"添加权限 > 新建自定义策略",策略内容如下:

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["oss:PutObject"],
      "Resource": ["acs:oss:*:*:venus-prod/uploads/*"]
    }
  ]
}
```

其中 `venus-prod` 需替换为 §6 中实际创建的 Bucket 名称。

### 3.3 记录角色 ARN

角色详情页顶部显示完整 ARN,格式如下:

```
acs:ram::<主账号ID>:role/venus-uploader
```

记录该 ARN,后续配置 `OSS_STS_ROLE_ARN` 时使用。

## 4. 创建 RDS MySQL 实例

### 4.1 创建实例

1. 进入云数据库 RDS 控制台,单击"创建实例"。
2. 按下表选择配置:

| 配置项 | 推荐值 | 说明 |
|---|---|---|
| 计费方式 | 包年包月 | 长期使用费用低于按量付费 |
| 数据库类型 | MySQL 8.0 | 与项目开发版本一致 |
| 系列 | 高可用版(生产环境)或基础版(测试/低预算) | 高可用版参考月价 350 至 550 元;基础版 120 至 220 元 |
| 规格 | 1 核 2 GB | 支持在线升配 |
| 存储 | ESSD PL0,20 GB | 支持在线扩容,不支持缩容 |
| 地域与可用区 | 与 ECS 相同 | 保证 VPC 内网连通 |
| 网络类型 | 专有网络 VPC,与 ECS 同一 VPC | 必须与 ECS 处于同一 VPC |

生产环境建议使用高可用版。

### 4.2 创建数据库账号

在实例详情页,选择"账号管理 > 创建账号":

- 账号名:`venus`
- 账号类型:高权限账号
- 密码:设置强密码并记录

数据库账号与阿里云登录账号无关,应用连接串使用此账号。

### 4.3 创建数据库

在实例详情页,选择"数据库管理 > 创建数据库":

- 库名:`venus`
- 字符集:`utf8mb4`

### 4.4 配置白名单

在实例详情页,选择"数据安全性 > 白名单设置",修改默认分组:

- 若 ECS 已创建,添加 ECS 的内网 IP。
- 若 ECS 尚未创建,可先添加所在 VPC 网段(例如 `192.168.0.0/16`),待 ECS 创建后收窄至具体内网 IP。

**严禁**将白名单设置为 `0.0.0.0/0`。

### 4.5 记录连接信息

在实例详情页,选择"数据库连接",记录内网地址与端口:

- 内网地址格式:`rm-xxxxxx.mysql.rds.aliyuncs.com`
- 端口:`3306`

使用内网地址而非外网地址。最终连接串将在服务器 `/etc/venus-4s/.env` 中拼装:

```
DATABASE_URL=mysql+aiomysql://venus:<密码>@rm-xxxxxx.mysql.rds.aliyuncs.com:3306/venus?charset=utf8mb4
```

### 5.1 创建实例

1. 进入云数据库 Redis 控制台,单击"创建实例"。
2. 按下表选择配置:

| 配置项 | 推荐值 | 说明 |

| 网络类型 | 专有网络 VPC,与 ECS 同一 VPC | |
| 密码 | 创建时设置强密码并记录 | 用于应用连接 |

### 5.2 配置白名单

在实例详情页选择"白名单设置",添加 ECS 内网 IP,规则同 §4.4。

### 5.3 记录连接信息

在实例详情页选择"连接信息",记录专有网络(内网)连接地址与端口:

- 内网地址格式:`r-xxxxxx.redis.rds.aliyuncs.com`
- 端口:`6379`

最终连接串:

```
REDIS_URL=redis://:<密码>@r-xxxxxx.redis.rds.aliyuncs.com:6379/0
```

**注意**:密码前的冒号不可省略。该格式表示空用户名加密码。若省略冒号,连接串将被解析为用户名格式,导致认证失败。

## 7. 开通短信服务

### 7.1 开通服务

进入短信服务控制台,按引导开通国内消息服务。

### 7.2 申请签名

在"国内消息 > 签名管理"下单击"添加签名":

- 签名内容:公司简称或产品名称,例如"医美 4S"
- 签名用途:验证码类
- 附件:营业执照(使用他人企业名义需附授权书)

审核周期通常为 1 至 3 个工作日。审核通过后的签名名称即为 `ALI_SMS_SIGN` 的配置值。

### 7.3 申请模板

在"国内消息 > 模板管理"下单击"添加模板":

- 模板类型:验证码
- 模板名称:例如"医美 4S 登录验证码"
- 模板内容示例:`您的验证码是${code},5分钟内有效,请勿泄露。`

模板内容必须包含 `${code}` 变量。审核周期通常为数小时至一天。审核通过后获得模板 Code(格式为 `SMS_XXXXXXXXX`),即为 `ALI_SMS_TEMPLATE_LOGIN` 的配置值。

若签名或模板未通过审核,`apps/api/app/services/sms/aliyun.py` 将拒绝发送短信并抛出异常。

## 10. 创建 ECS 实例

### 10.1 创建实例

1. 进入云服务器 ECS 控制台,单击"创建实例"。
2. 按下表配置:

| 配置项 | 推荐值 |
|---|---|
| 计费方式 | 包年包月 |
| 地域与可用区 | 与 RDS、Redis、OSS 相同 |

## 11. 域名、ICP 备案与 SSL 证书

### 11.1 购买域名并实名认证

进入阿里云域名控制台购买域名,例如 `venus.example.com`。购买后立即完成实名认证。实名认证通常在 1 个工作日内完成,认证未通过前无法解析。

### 11.2 ICP 备案

大陆地域 ECS 对外提供 80、443 服务时,依据法规需完成 ICP 备案,否则相关端口将被拦截。

进入阿里云备案控制台,选择"新增网站",绑定当前 ECS 实例,按流程提交管局审核。备案周期通常为 1 至 2 周。

香港及境外地域 ECS 无需备案,但大陆访问速度较慢。

建议在项目立项、ECS 购买后立即启动备案流程。

### 11.3 配置 DNS 解析

在域名控制台"解析设置"中添加解析记录:

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `@` | ECS 公网 IP |
| A | `www` | ECS 公网 IP |

解析生效通常需要数分钟。可通过 `ping <域名>` 验证解析是否指向 ECS IP。

### 11.4 申请 SSL 证书

**方式一:阿里云免费 DV 证书(推荐)**

1. 进入阿里云 SSL 证书控制台,单击"申请免费证书"。
2. 类型选择"DV 单域名",填写域名并完成 DNS 校验。
3. 校验通过后下载 Nginx 格式证书。解压后包含两个文件,重命名为 `fullchain.pem` 与 `privkey.pem`。

**方式二:Let's Encrypt(webroot 校验)**

在 ECS 上安装 certbot,执行:

```bash
certbot certonly --webroot -w /srv/venus-4s/certbot -d <域名>
```

证书文件位于 `/etc/letsencrypt/live/<域名>/` 下。

## 12. web 容器 nginx 说明

ECS 上无需单独安装 nginx。web 容器镜像内已包含 nginx,配置文件为项目仓库中的 `infra/nginx/edge.conf`,通过 Docker Volume 挂载到容器内。

容器内 nginx 的职责:

1. 监听 80 端口:放行 `/.well-known/acme-challenge/` 路径用于证书续期,其他请求 301 跳转至 HTTPS。
2. 监听 443 端口:进行 TLS 终止,读取 `nginx/ssl/fullchain.pem` 与 `nginx/ssl/privkey.pem`。
3. 静态资源托管:前端构建产物已打包进镜像的 `/usr/share/nginx/html`,支持 SPA fallback 至 `index.html`。
4. API 反向代理:`/api/` 转发至 api 容器 8000 端口;`/api/analyze/*/stream` 路径启用 SSE 长连接配置(关闭 buffering、超时时间 3600 秒)。

本阶段仅需准备 SSL 证书文件 `fullchain.pem` 与 `privkey.pem`。域名无需修改 `edge.conf`,配置中已使用 `server_name _;` 通配。

## 13. 生成应用侧密钥

除阿里云资源外,应用还需要以下三项密钥,由本地生成后写入服务器 `/etc/venus-4s/.env`。

在本地执行:

```bash
openssl rand -hex 32        # 输出用于 JWT_SECRET
openssl rand -base64 32     # 输出用于 PHONE_DEK_BASE64
openssl rand -hex 32        # 输出用于 PHONE_HMAC_KEY
```

**重要**:`PHONE_DEK_BASE64` 与 `PHONE_HMAC_KEY` 生产环境部署后不可修改。修改后已加密存储的手机号将无法解密。生成后请立即离线备份。
