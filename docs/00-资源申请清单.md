# 00 · 资源申请清单

## 使用说明

本清单列出 venus-4s 项目上线所需的全部外部资源。适用读者:项目采购、甲方对接人、部署负责人。

- 每项标注**用途 / 规格 / 申请方式 / 参考费用 / 负责方**。
- 全部资源就绪后进入 [01-部署前准备.md](./01-部署前准备.md) 完成配置。
- 参考费用为华东 1(杭州)包年包月折算月价,以阿里云官方[价格计算器](https://www.aliyun.com/price/product)为准。

**依赖关系**:项目当前已依据代码 `apps/api/pyproject.toml`(引入 `oss2` / `alibabacloud-green20220302` / `alibabacloud-dysmsapi20170525`)、`apps/api/app/core/config.py`(Settings 字段)与 `infra/docker-compose.ecs.yml` 架构盘点得出以下清单。

---

## A. 阿里云资源(必需)

### A.1 ECS 云服务器

| 项目 | 说明 |
|---|---|
| 用途 | 部署主机,运行 Docker(web、api、cron 三个容器) |
| 数量 | 1 台 |
| 推荐规格 | 2 核 4 GB;系统盘 40 至 100 GB ESSD;公网带宽 3 至 5 Mbps |
| 镜像 | Alibaba Cloud Linux 3 或 Ubuntu 22.04 |
| 地域 | 华东 1(杭州)或客户偏好区域(**其他云资源必须与 ECS 同地域同 VPC**) |
| 计费 | 包年包月 |
| 申请路径 | 阿里云控制台 → 云服务器 ECS → 创建实例 |
| 参考月价 | 150 至 300 元(3 Mbps 带宽) |
| 负责方 | 部署负责人 |

### A.2 RDS MySQL

| 项目 | 说明 |
|---|---|
| 用途 | 业务数据库,存储用户信息(手机号加密)、照片元数据、分析报告、审计日志 |
| 数量 | 1 实例 |
| 推荐规格 | MySQL 8.0 高可用版(主备)/ 1 核 2 GB / ESSD PL0 20 GB |
| 网络 | 专有网络 VPC,与 ECS 同一 VPC;不开启公网访问 |
| 字符集 | utf8mb4 |
| 计费 | 包年包月 |
| 申请路径 | 阿里云控制台 → 云数据库 RDS → 创建实例 |
| 参考月价 | 高可用版 350 至 550 元;基础版单机 120 至 220 元 |
| 负责方 | 部署负责人 |
| 备注 | 项目存储真实用户手机号(敏感个人信息),建议高可用版 |

### A.3 KVStore Redis

| 项目 | 说明 |
|---|---|
| 用途 | 限流计数、短信验证码、会话缓存 |
| 数量 | 1 实例 |
| 推荐规格 | Redis 社区版 标准版(主从)/ 1 GB |
| 网络 | 专有网络 VPC,与 ECS 同一 VPC;不开启公网访问 |
| 密码 | 创建时设置强密码 |
| 计费 | 包年包月 |
| 申请路径 | 阿里云控制台 → 云数据库 Redis 版 → 创建实例 |
| 参考月价 | 90 至 160 元 |
| 负责方 | 部署负责人 |

### A.4 OSS 对象存储

| 项目 | 说明 |
|---|---|
| 用途 | 存储用户上传的照片、生成的分析报告 |
| 数量 | 1 Bucket(建议命名 `venus-prod`) |
| 读写权限 | **私有**(不得公共读写) |
| 地域 | 与 ECS 同地域 |
| 生命周期规则 | `uploads/` 前缀 10 天后自动删除(与代码 `PHOTO_TTL_DAYS=10` 对齐) |
| 计费 | 按用量(存储 + 请求 + 流量) |
| 申请路径 | 阿里云控制台 → 对象存储 OSS → 创建 Bucket |
| 参考月价 | 存储量 10 GB 以内 + ECS 走内网 Endpoint 时约 5 至 20 元 |
| 负责方 | 部署负责人 |

### A.5 容器镜像服务(ACR)

| 项目 | 说明 |
|---|---|
| 用途 | 存储 api、web 镜像,ECS 拉取 |
| 版本 | 个人版(免费) |
| 命名空间 | `venus`(私有) |
| 仓库 | `api`、`web`(均为私有) |
| 申请路径 | 阿里云控制台 → 容器镜像服务 → 开通个人版实例 |
| 参考月价 | 免费 |
| 负责方 | 部署负责人 |

### A.6 RAM 子账号与角色

| 项目 | 说明 |
|---|---|
| 用途 | 应用调用云 API 的凭证(短信、OSS、STS、内容审核) |
| 子账号 | 1 个(命名 `venus-app`),仅勾选 OpenAPI 访问方式 |
| 角色 | 1 个(命名 `venus-uploader`),用于 STS AssumeRole 换取前端直传临时凭证 |
| 授权 | 子账号授予:`AliyunDysmsFullAccess`、`AliyunOSSFullAccess`、`AliyunSTSAssumeRoleAccess`、`AliyunYundunGreenWebFullAccess` |
| 申请路径 | 阿里云控制台 → 访问控制 RAM → 用户 / 角色 |
| 参考月价 | 免费 |
| 负责方 | 阿里云主账号持有人 |
| 备注 | 应用严禁使用主账号 AccessKey |

### A.7 短信服务(dysms)

| 项目 | 说明 |
|---|---|
| 用途 | 用户登录验证码 |
| 需申请项 | 签名(1 个)+ 验证码模板(1 个);模板内容需含 `${code}` 变量 |
| 审核周期 | 签名 1 至 3 个工作日;模板通常几小时至一天 |
| 计费 | 按条计费,国内短信约 0.045 元 / 条 |
| 申请路径 | 阿里云控制台 → 短信服务 → 国内消息 → 签名管理 / 模板管理 |
| 参考月价 | 每月 5000 条约 225 元,10000 条约 450 元(依业务量) |
| 负责方 | 阿里云主账号持有人 + 甲方(提供营业执照) |
| 备注 | 签名申请需提交营业执照;使用他人企业名义需授权书 |

### A.8 内容审核(Green)

| 项目 | 说明 |
|---|---|
| 用途 | 用户上传图片与文本的合规审核 |
| 服务名 | 内容安全(内容审核 2.0) |
| 推荐区域 | 华东 2(上海)`cn-shanghai` |
| 计费 | 按次计费:图片审核约 1.5 元 / 千次;文本审核约 1 元 / 千次 |
| 申请路径 | 阿里云控制台 → 内容安全 → 开通服务 |
| 参考月价 | 每月 5000 次约 8 至 15 元(依业务量) |
| 负责方 | 阿里云主账号持有人 |
| 备注 | 上线前需在应用侧补齐 SDK 调用(`apps/api/app/services/moderation.py` 当前为 `NotImplementedError`) |

## B. 域名、备案与 SSL 证书

### B.1 域名

| 项目 | 说明 |
|---|---|
| 用途 | 对外访问入口(如 `venus.example.com`) |
| 数量 | 1 个 |
| 申请路径 | 阿里云域名 或第三方注册商 |
| 参考费用 | `.com` 约 60 至 100 元 / 年;`.cn` 约 30 至 40 元 / 年 |
| 负责方 | 甲方(建议注册在甲方名下) |
| 备注 | 购买后需立即完成**实名认证**,约 1 个工作日 |

### B.2 ICP 备案

| 项目 | 说明 |
|---|---|
| 用途 | 大陆地域 ECS 对外提供 80 / 443 服务的**法律强制要求** |
| 审核周期 | **1 至 2 周**(项目最慢的一步) |
| 申请路径 | 阿里云控制台 → 备案 |
| 参考费用 | 免费 |
| 负责方 | 甲方(需提供营业执照、法人身份证、网站负责人信息) |
| 备注 | **立项后立即启动**,不要等应用做完才办;香港 / 境外 ECS 免备案,但大陆访问慢 |

### B.3 SSL 证书

| 项目 | 说明 |
|---|---|
| 用途 | HTTPS 加密(小程序、公众号强制要求) |
| 类型 | DV 单域名证书 |
| 有效期 | 1 年(阿里云免费 DV)或 90 天(Let's Encrypt,自动续期) |
| 申请路径 | 阿里云控制台 → SSL 证书 → 申请免费证书 |
| 参考费用 | 免费 |
| 负责方 | 部署负责人 |

## F. 申请顺序(时间线建议)

以"上线日"为 D 日反推:

| 时间 | 动作 | 负责方 |
|---|---|---|
| D - 15 天 | 甲方备齐 §D 全部材料;提交 ICP 备案(**最耗时,先启动**) | 甲方 + 部署负责人 |
| D - 15 天 | 主账号完成实名认证 | 甲方 |
| D - 15 天 | 建 RAM 子账号 `venus-app` 并授权,生成 AccessKey | 部署负责人 |
| D - 10 天 | 采购 ECS、RDS、KVStore(包年包月);开通 OSS、ACR、内容审核 | 部署负责人 |
| D - 10 天 | 提交短信签名与登录模板审核 | 部署负责人 + 甲方(营业执照) |
| D - 10 天 | 域名购买 + 实名认证 | 甲方 |
| D - 8 天 | 部署负责人本地构建镜像、推送 ACR,详见 [02-部署实施.md](./02-部署实施.md) | 部署负责人 |
| D - 3 天 | ICP 备案通过 → 域名解析 A 记录指向 ECS → 申请 SSL 证书 | 甲方 + 部署负责人 |
| D - 2 天 | ECS 拉镜像启动;执行完整验证,详见 [03-部署验证.md](./03-部署验证.md) | 部署负责人 |
| D - 1 天 | 甲方在微信公众号后台添加业务域名(如接入微信) | 甲方 |
| D 日 | 正式对外访问 | — |
