# 双击启动 venus-4s

收到 `venus-4s-portable.zip` 后，按下面三步操作即可。

---

## 1. 解压

解压到任意目录，比如 `D:\projects\venus-4s`。**路径里不要有空格或中文**（pnpm/poetry 偶尔会因路径有空格出问题）。

---

## 2. 安装一次性的工具（首次启动前）

下面 4 个是必须的，第 5 个可选（不装 Docker 就得自己在本机起 MySQL 8 + Redis）。

| 工具 | 下载/装法 | 检查 |
|---|---|---|
| **Python 3.11+** | <https://www.python.org/downloads/> 装时勾选 *Add Python to PATH* | `python --version` |
| **Poetry** | 装完 Python 后开 cmd 跑 `pip install poetry` | `poetry --version` |
| **Node.js LTS** | <https://nodejs.org/> | `node --version` |
| **pnpm** | 装完 Node 后跑 `npm i -g pnpm` | `pnpm --version` |
| **Docker Desktop**（可选） | <https://www.docker.com/products/docker-desktop/> | `docker --version` |

### Poetry 找不到怎么办

`pip install poetry` 默认装到 `%APPDATA%\Python\Python311\Scripts\`，这个目录有时不在 PATH。把它加到用户 PATH：

```cmd
setx PATH "%PATH%;%APPDATA%\Python\Python311\Scripts"
```

或者用 `pipx install poetry` 也行（pipx 会自动配 PATH）。

### 不想装 Docker

你需要本机已有：
- MySQL 8，账号 `venus` / 密码 `devpass`，建好库 `venus`
- Redis 7+ 在 `localhost:6379` 监听

或者改 `config\dev.env` 里的 `DATABASE_URL` / `REDIS_URL` 指向你自己的服务。

---

## 3. 双击启动

双击项目根目录下的 **`start-dev.bat`**。

脚本会自动：
1. 检查上面的工具是否齐全（缺哪个会提示）
2. `config\dev.env` 不存在就从 `config\dev.env.example` 复制一份（**复制完记得填里面的连接串和密钥**）
3. 起 MySQL / Redis（有 Docker 就用容器，没有就探测本机服务）
4. 装 Python 后端依赖到 `apps\api\.venv`（首次约 3-5 分钟，下 ~90 个包）
5. 跑数据库迁移
6. 装前端依赖（首次约 2-5 分钟）
7. 在两个新 cmd 窗口里分别启动 API 和 Web

日志落在 `logs\startup.log`。

**首次启动 5-15 分钟**，之后增量启动几秒钟。

> 只装 H5（`apps\web`）的依赖。要开发小程序端，另在项目根目录跑一次 `pnpm install`，一次装齐 workspace 全部包。

完成后浏览器访问：
- 前端入口：<http://localhost:5173/>
- 后端 API 文档：<http://localhost:8080/docs>

---

## 关闭

- API / Web：直接关掉双击启动出来的两个 cmd 窗口
- Docker 容器：双击 **`stop-dev.bat`**（不用 Docker 时无需此步）

---

## 常见问题

**问：脚本报"未检测到 pnpm/poetry/docker"**
照提示装对应工具，然后重新双击 `start-dev.bat`。

**问：MySQL 3306 端口已占用**
你机器上已有别的 MySQL。两个办法：
- 停掉本机 MySQL，让脚本启 Docker 容器
- 或保留本机 MySQL，建账号 `venus/devpass` + 库 `venus`，关掉 Docker Desktop（脚本会改走本机服务路径）

**问：浏览器打开 5173 是白屏**
看 vite 那个 cmd 窗口的日志，通常是 vite 还没启动完，等几秒刷新。如果有报错，把日志发回来。

**问：API 返回 500**
看 uvicorn 那个 cmd 窗口日志，通常是数据库迁移没跑或 `config/dev.env` 配置不对。

**问：双击后窗口一闪而过**
说明脚本启动时报错就退了。改成：在项目目录开 cmd，手敲 `start-dev.bat` 跑，错误信息就不会消失。

## 文件清单

| 文件 | 作用 |
|---|---|
| `start-dev.bat` | 一键装依赖并启动 |
| `stop-dev.bat` | 停 Docker 容器 |
| `make-distribution.bat` | （仅原作者用）重新打 zip 给别人 |
| `config/dev.env` | 后端环境变量（数据库/密钥/LLM 配置） |
| `infra/docker-compose.dev.yml` | Docker 服务定义 |
