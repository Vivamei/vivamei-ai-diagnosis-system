## 关键决策

- **OSS 走直传**：前端拿后端签的临时上传凭证直接传到 OSS（避免 Python 进程 IO 阻塞，节省带宽）
- **SSE 而非 WebSocket**：4S 报告只是服务端单向流式输出，SSE 更轻；FastAPI 用 `StreamingResponse` 原生支持
- **LLM 服务是独立进程**（同事提供），FastAPI 通过 HTTP/SSE 调用，本地用 mock 服务联调
- **Redis 承担三件事**：短信验证码、SSE 任务进度（断线重连续传）、接口限流（基于 IP + 手机号）
- **Nginx 同时托管前端静态资源 + 反代 API**，单机部署最简
